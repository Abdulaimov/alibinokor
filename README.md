# Али Бинокор — 3D-сайт жилого комплекса

Интерактивный 3D-сайт ЖК «Али Бинокор» (Душанбе) для продажи квартир. Сделан студией Jomi Studio.
Покупатель крутит комплекс, выбирает блок и этаж, открывает этаж в разрезе с мебелью, смотрит
планировку квартиры и гуляет по ней внутри. Языки: русский и таджикский (переключатель в шапке).
Цен и статусов «продана / свободна» на сайте нет: так решил заказчик.

## Что в модели

| | |
|---|---|
| Блок А | стеклянная башня 24 этажа, квартиры на 3–24 (12 на типовом этаже, 10 на 9–10 и 20–21 с террасами) |
| Блоки Б и Г | 22 этажа, квартиры на 3–22 (15 на этажах 3–18, 14 на 19–22) |
| Блоки В и Д | 20 и 22 этажа, только снаружи (соседние блоки комплекса) |
| Этажи 1–2 | магазины во всех блоках: витрины, внутри полки, прилавки, люди |
| Окружение | двор по генплану: детсад на 300 мест, площадки, футбольное поле, парковки, газоны, деревья; больница (№ 13 генплана), школа (на севере), улицы с машинами, городская застройка вокруг |

Откуда что взято:

- **Планировки** (`blender/ab/plans.json`) прочитаны из PDF архитектора скриптом
  `tools/ab/extract_plan.py`: стены, колонны, окна, комнаты, квартиры. Названия комнат распознаны
  по надписям на листах, площадь и число комнат каждой квартиры совпадают с подписями на листах.
  Этажи без отдельного листа повторяют ближайший типовой (так сказал заказчик).
  Двери тоже с листов: одна дверь между двумя комнатами, открывается в ту сторону, куда она
  нарисована. Маленькие технические лоджии (до 2,6 м²) — со стенами и одной дверью, как на листе.
- **Генплан** (`build/site_raw.json`) — `tools/ab/site_map.py`: асфальт, газоны, мощение,
  площадки, деревья, номера зон.
- **Фасады** — по рендерам застройщика (`blender/ab/towers.py`, `podium.py`, `roof.py`).
- **Высоты этажей**: разрезов в материалах нет, приняты 4,5 м (1 этаж), 4,2 м (2 этаж), 3,3 м дальше.

## Управление

- **Комплекс:** перетащите — поворот, колесо — масштаб. Нажмите на букву блока или на блок в списке слева.
- **Блок:** наведите на этаж и нажмите (или выберите этаж в списке). Этаж откроется в разрезе.
- **Этаж:** нажмите на квартиру на модели или в списке справа — карточка с планировкой.
- **Квартира:** «Прогулка по квартире в 3D». Внутри: перетащите — осмотреться, нажмите на пол — перейти,
  WASD / стрелки. На телефоне — джойстик. Esc — назад.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # готовый сайт в dist/ (относительные пути, можно открыть с любого сервера)
```

## Публикация на GitHub Pages

Каждый push в `main` собирается и публикуется `.github/workflows/deploy.yml`
(в настройках репозитория: Settings → Pages → Source: GitHub Actions).

## Пересборка модели

Нужен Blender 5.x (`/Applications/Blender.app`). Библиотеки Python ставятся в папку проекта:

```bash
/Applications/Blender.app/Contents/Resources/5.2/python/bin/python3.13 -m pip install --target .pylib shapely pymupdf opencv-python-headless scipy pillow
/Applications/Blender.app/Contents/Resources/5.2/python/bin/python3.13 -m pip install --target .pylib-blender --no-deps shapely
tools/ab/py tools/ab/extract_plan.py   # только если поменялись PDF планов
tools/ab/py tools/ab/site_map.py       # только если поменялся генплан
blender/export_ab.sh                   # -> public/models/ali_binokor.glb, src/model/*.json
```

PDF заказчика лежат вне репозитория: `../00_Материалы_клиента/`.

## Проверки

```bash
npm run dev -- --port 5191 &
node tools/check_app.mjs               # все квартиры, этажи, клики, прогулки, таджикский язык
node tools/shots.mjs build/shots       # кадры с фиксированных камер (tools/views.mjs)
tools/ab/py tools/ab/compare.py RENDER.jpg build/shots/render1.png build/cmp1.png   # рендер и модель рядом
tools/ab/py tools/ab/overlay_plans.py  # распознанные планы поверх листов PDF
tools/ab/py tools/ab/check_doors.py    # двери: в чужую квартиру, две в одну комнату, комната без входа
node tools/ab/notes.mjs                # комнаты, где не встала мебель (пустой ответ — всё обставлено)
FLAT_LANG=ru tools/ab/py tools/ab/draw_flat.py A 1 build/flat.png   # одна квартира: стены, двери, куда открываются
node tools/hover_shot.mjs B 10 3 build/hover.png   # подсветка квартиры под курсором
```
