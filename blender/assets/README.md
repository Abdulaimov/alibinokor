# Poly Haven assets (CC0): fetched by fetch_assets.py

`python3 blender/assets/fetch_assets.py` downloads the sky, texture sets and tree models listed in
`ASSETS` into `hdri/`, `textures/` and `models/` here (git-ignored); `scripts/build_web_assets.py`
turns them into the small files the site loads from `public/`. Authors and licences: `ASSETS.md`.
